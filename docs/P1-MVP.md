## 交付内容

已实现可运行的 Next.js 工作台 `/dashboard/workbench`，不是设计稿。首页提供工作台入口，侧栏保留团队与账户设置。中文优先，桌面和手机响应式布局。

- 客户需求：中文/英文输入，四种服务类型（网站、设计、翻译、咨询），创建、本人列表、查看与编辑；PostgreSQL 保存，编辑递增版本。
- AI 分析：服务建议、预算原文、币种、交期原文、核心要求摘录、缺失项与追问；分析结果按需求版本保存。Demo 明确标注；支持真实 OpenAI-compatible Chat Completions 接口配置。
- 团队价目表：owner 新增服务项目、币种与整数分单价；当前团队成员可查看。报价按 AI 建议服务匹配相同币种的价目，不换汇。
- 报价：生成草稿，每项初始数量明确为 1，人工核对工作量；编辑项目、数量、单价、币种、语言和说明；金额由程序以整数最小货币单位计算，服务端重新验证和计算。
- 人工确认：独立勾选与确认操作；未保存修改不可确认。服务端要求 `confirmed: true` 和当前报价版本，拒绝旧需求版本，确认后锁定，保留确认人、时间及完整历史快照。确认不会发送给客户，也不会触发付款。
- 历史：生成、修改、确认在同一事务内保存快照，保留原报价与价格，不被后续价目或需求修改覆盖。
- 三个可一键载入的虚构客户案例；完整自动化回归与 PostgreSQL CI 服务配置。

## 启动与配置

沿用 P0 的 Node.js 24、pnpm 9.15.9、Next.js 16.4.2、React 19.3.1、Drizzle/PostgreSQL。没有新增依赖，没有更换认证。

```sh
pnpm install --frozen-lockfile
# 按 .env.example 创建私有 .env；配置专用本地开发数据库和随机 AUTH_SECRET。
# 必须保持 LEGACY_STRIPE_ENABLED=false。
pnpm db:migrate
pnpm dev
```

通过 `/sign-up` 创建自己的开发账号，登录后访问 `/dashboard/workbench`。没有公开默认账号。owner 先在“服务价目表”新增服务和币种，再载入案例并保存、分析、生成报价。也可使用 README 的显式授权开发 seed。

默认 `DEALPILOT_AI_MODE=demo`：本地保守规则提取，**没有真实模型调用**。Demo 不预测项目规模或报价工作量。

真实模型配置全部为服务端环境变量，不能使用 `NEXT_PUBLIC_`：

```dotenv
DEALPILOT_AI_MODE=live
DEALPILOT_AI_ENDPOINT=https://api.openai.com/v1/chat/completions
DEALPILOT_AI_MODEL=your-model-name
DEALPILOT_AI_API_KEY=your-private-server-key
```

使用支持 `response_format: {type: json_object}` 的 OpenAI-compatible Chat Completions 提供方。endpoint 必须 HTTPS，默认 OpenAI；不会购买、开通或自动切换收费服务。网络策略也必须允许该提供方。live 缺少配置或失败时明确报错，不静默降级至 Demo。

## 权限与 AI 边界

- API 的所有读写先验证现有签名会话、数据库用户及凭据版本。每次业务事务再查询活跃用户与当前 membership；从服务器确定 userId/teamId，不接受客户端归属字段。
- 需求、分析、报价与历史均按“本人 + 当前团队”筛选。同团队其他成员及其他 owner 也不能读取或修改本人的客户需求。价目表按团队共享，仅 membership owner 可写；全局 user.role 不授予权限。
- 沿用 P0 按 membership id 排序的当前团队规则；没有新增多团队切换 UI。
- 事务锁保护成员撤销、需求更新和报价确认；版本检查拒绝并发覆盖。AI 调用前后再次验证权限与需求版本，避免保存过期分析。
- API 变更要求同源 Origin 和 JSON；请求与模型响应均限制 64KB；返回 private/no-store。AI 25 秒超时，不重定向，不提供工具调用。
- 固定 system 指令将用户 JSON 视作不可信数据，禁止执行其中的指令、泄密与补造事实。Zod 严格校验结构、枚举与长度；预算、交期、核心要求必须是原文逐字摘录，币种必须有显式标记。缺少预算、币种、交期时强制标为缺失。
- AI 输出只是建议；原文摘录校验不等于验证客户陈述的真实性，也无法证明语义绝无误读或提示注入。预算与交期均展示原文，需要人工核实。报价金额完全脱离模型，由程序计算，不执行模型文本或渲染任意 HTML。
- AI 失败记录固定事件、模式及随机参考编号，不记录密钥、客户原文或提供方响应。网页展示可重试的友好提示；失败不写入成功分析。
- Stripe 开关、安全认证、公开用户字段白名单和 P0 修复保留。本期未接支付、未访问本草云、未购买 API、未部署 Railway、未修改 main、未自动合并。
