# P1 B3 最终阻断修复报告

审查基线：`bc4fda2ac86544d0632ee5fdb9f963b51d8ecf52`。目标为原 Draft PR #2 / `feature/p1-ai-quotation`。本次仅修改 B3 事实验证、策略身份及对应回归测试，不修改 main、B1/B2 业务逻辑或数据库结构。

## 修复及行为差异

- 金额使用有限语法扫描完整原文，不计算汇率，也不把金额前缀当作事实。`预算10万元`、`预算1.5万元`、`人民币 10 万元`、`USD 2 million`、`USD 3 thousand` 保留完整金额及单位。原先可能截为 `人民币 10` / `USD 2`，现在不再通过。
- 支持显式 CNY/USD/EUR 标记、人民币千/万/元、英文 thousand/million、合法千分位及至多两位小数；紧接预算标签的中文 `数字万元/千元/元` 可识别 CNY。不支持亿、billion、trillion、k、未知币种、混合单位、范围、畸形分组或更高精度时返回 null。空白不是单位结束边界，不能通过局部子串降级为小金额。
- 只有具有预算/交期业务标签、完整边界且语境通过验证的事实可用。参考、示例、否定、不确定、取消、问句及冲突候选采用 fail-closed；同时检查相邻句。该规则刻意保守，可能要求用户重述本来正确的信息。
- 日期只接受有效公历完整日期：中文年月日、ISO 日期或英文完整月份日期；不把年份等部分内容当作完整交期。日期之后的取消、待定及英文否定也会使事实未知；不自动推断相对日期、时区或日期格式。
- Demo 与 Live 共用服务端 `validateEvidence`。金额必须与完整可信提取结果相等；日期必须为完整日期。已识别的注入文本整体隔离；追问始终由可信服务端模板重新生成，丢弃模型问题。
- 策略升级为 `p1-safe-v3`，Demo 身份升级 `conservative-demo-v3`。现有 profile 含策略版本，因此 v2 成功缓存不命中 v3；旧策略分析不能生成新报价，旧策略草稿不能确认。已确认报价及历史快照保持原样。

## 剩余限制及验收边界

规则是有限语法的保守验证，不宣称理解所有自然语言或识别所有注入变体。未支持的金额/日期需人工澄清，价格表和最终报价仍须人工核对。真实模型兼容性、质量和提供方计费行为尚未实测；启用前仍须单独审核模型配置、预算/配额及小规模测试方案。支付保持禁用，本报告不批准真实模型收费或支付上线。
